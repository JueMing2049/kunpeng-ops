01 / 模板

四套骨架，四种读法

点开任何一个都是完整可用的页面，不是截图。

01 · 研究备忘 长文
单栏长文 + 边注 + 折叠证据。适合深度研究、文献综述、一页纸容不下的判断。
02 · 方案评审 图显前置
编排图 + 排期 + 架构 + 风险矩阵 + 决策卡。适合立项、架构评审、外包提案。
03 · 项目复盘 因果
KPI + 时间轴 + 前后对比滑块 + 归因卡 + 行动项。适合阶段复盘、事故复盘。
04 · 数据简报 滚动叙事
sticky 图 + 滚动步进 + 大数字。适合给不看长文的人做汇报、季度简报。
实战重排 · 《HTML 交互范式研究报告》v2 同一论点 · 换骨架
把 77KB 的静态研究报告用 memo 骨架重排：参考盘点可筛选、决策呈议变成可点选的卡、章节可批注锚定、四张机制图循环演示，并附改版对照章节。目录旁可一键切换「专业／通俗」双表达——通俗版以「一起改一份稿子」贯穿全篇。论点一字未删，读法完全变了。
02 / 选型

怎么选：看「读者要做什么」

不要按行业选，按读者的动作选。读者要判断就选评审，要理解就选备忘。

读者的动作选因为不要用它做
读完后要「判断对错」01 备忘长文能承载论证链，边注能放异议会议汇报（太长）
读完后要「决定做不做」02 评审图在第三屏出现，争的是结构不是文字事后解释（该用复盘）
读完后要「知道哪里错了」03 复盘时间轴给因果顺序，对比给证据立项（该用评审）
读完后要「记住三个数」04 简报一屏一结论，滚动即翻页细致推演（信息密度不够）
!
可以混，但只有一个主骨架
评审模板里可以嵌一个复盘时间轴，但不要两套叙事并列——读者会不知道该顺着谁读。派生内容一律降级为组件，不升格为章节。

04 / 动效

七种原语，全部零依赖

原语机制成本什么时候别用
渐入 .revealIntersectionObserver + transform极低首屏第一段（会闪）
数字滚动 data-countrAF + easeOutCubic极低数字本身不重要时（纯干扰）
SVG 描边 .drawpathLength="1" + dashoffset低节点多于 8 个（等太久）
条形生长 .barCSS 变量 --w + transition极低数据要精确读数时
呼吸 / 涟漪SMIL animate 或 keyframes低同屏超过 2 个（抢注意力）
滚动驱动 .sdaanimation-timeline:view()零 JS需要精确帧控制时（用 GSAP）
路径流动SMIL animateMotion + mpath低路径会频繁变化时

4.1现场演示

这一段用的是原生滚动驱动（animation-timeline:view()）：进入视口时淡入上移，不需要任何 JS。在不支持的浏览器里它会直接显示，不影响阅读。

05 / 技术

五条技术约定，撑起全部零依赖

①
pathLength="1" 做描边动画

不用 JS 测量路径长度。stroke-dasharray:1; stroke-dashoffset:1 直接通用于任意 path/circle/rect。

②
:has() 做兄弟联动

悬停一个节点、其余淡出，纯 CSS 实现。这是 2024 之后才敢用的写法，现在已是基线。

③
animation-timeline 做滚动叙事

进度条、渐入、视差全部交给 CSS；只有「按步切换」才用 IntersectionObserver。

④
CSS 变量做数据绑定

--w:76% 控制条形，--cut:50% 控制对比滑块。数据在 HTML 属性里，样式在 CSS 里。

⑤
clip-path 做前后对比

两层图叠放，一层按百分比裁切。比 canvas 简单一个数量级。

↺
降级策略不是可选项
关闭 JS：内容全在，交互失效，仍可读。prefers-reduced-motion：动效归零，布局不塌。打印：隐藏导航与工具条，卡片不跨页。三条都要在写第一行样式时就成立。
06 / 用法

三步，从模板到你的报告

01
复制模板，只换内容

保留所有 class 与 data-block，把文字和图换成你的。结构不动，样式就不会崩。

02
换品牌只改令牌

改 :root 里那 12 个颜色变量和 3 个字体栈，全站自动换皮，不用碰任何组件。

03
需要单文件就内联

跑一次 build.py，把 kit.css 与 kit.js 塞进 HTML，产出可邮件、可归档的单个文件。

目录结构

html-report-kit/
├─ index.html        ← 你在这里
├─ tpl-memo.html     长文 / 边注 / 折叠证据
├─ tpl-proposal.html 图显前置 / 决策卡
├─ tpl-retro.html    时间轴 / 前后对比
├─ tpl-brief.html    滚动叙事 / 简报
├─ kit.css           令牌 + 26 个组件
├─ kit.js            14 个交互模块
└─ build.py          内联成单文件
一个约定，值得坚持
每个 <section> 都带 data-block。它不是给样式用的，是给批注、版本、AI 定点重写用的。 块 id 一旦发布就不要改名——改了就断链。
